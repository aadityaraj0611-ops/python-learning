# Competitive Programming Tracker

A Python-based command-line application to record, display, and search solved competitive programming problems across platforms like Codeforces and LeetCode.

## Features

- **Add Solved Problems:** Record problem details such as name, platform, problem code, difficulty, and topic.
- **Display All Problems:** View all recorded problems with their details.
- **Search Problems:** Search using the problem name, problem code, or platform.
- **Automatic Problem IDs:** Each problem receives a unique ID.
- **Interactive Menu:** Navigate through the application using a simple menu-driven interface.

## Concepts Used

- Variables and data types
- Lists and dictionaries
- Functions
- Loops and conditional statements
- String methods (`lower()`)
- User input and output
- Searching through lists of dictionaries

## How to Run

1. Make sure Python 3 is installed.
2. Open the project directory in your terminal.
3. Run:

```bash
python3 main.py
```

## How to Use

1. Select **Add Solved Problem** to enter a problem.
2. Select **Display All Problems** to view recorded problems.
3. Select **Search Problems** to find a problem by name, code, or platform.
4. Select **Exit** to close the application.
