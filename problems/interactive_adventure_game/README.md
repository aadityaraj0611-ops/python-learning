# Interactive Adventure Game

## Description
An interactive, text-based adventure game developed using Python. Players explore different locations, collect items, fight enemies, manage their health, and attempt to discover a legendary treasure hidden in the castle.

## Features
- **Character Setup:** Enter a custom adventurer name.
- **Location Exploration:** Travel between the Village, Forest, Cave, and Castle.
- **Inventory Management:** Collect and use health potions and weapons.
- **Combat System:** Fight enemies using randomly generated damage.
- **Health Management:** Monitor health and restore it using potions.
- **Achievement System:** Unlock achievements by exploring and defeating enemies.
- **Win/Lose Conditions:** Find the legendary treasure or lose all your health.

## Locations and Enemies

| Location | Enemy |
|---|---|
| Village | Safe zone |
| Forest | Wolf |
| Cave | Goblin |
| Castle | Dark Knight |

## Technologies Used
- Python 3
- Random module

## How to Run

1. Make sure Python 3 is installed.
2. Open the project directory in Terminal.
3. Run:

```bash
python3 main.py
```
