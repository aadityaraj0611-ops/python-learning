# Movie Ticket Booking System

A menu-driven Python application that simulates a movie ticket booking system. Users can browse movies, check seat availability, book tickets, cancel bookings, and calculate total revenue.

## Features

- Display available movies and ticket prices.
- Display available and booked seats.
- Book movie tickets for different movies.
- Prevent duplicate seat bookings.
- Cancel existing bookings.
- Display all active bookings.
- Calculate total tickets sold.
- Calculate total ticket revenue.
- Handle invalid inputs using exception handling.

## Available Movies

| Movie | Ticket Price |
|---|---:|
| Avengers | Rs. 250 |
| Interstellar | Rs. 200 |
| Inception | Rs. 180 |

Each movie has 10 seats available.

## How to Run

Run the following command from the repository's root directory:

```bash
python3 problems/movie_ticket_booking_system/main.py
```

## Python Concepts Used

- Variables and data types

- While loops and for loops
- Conditional statements

## Storage

Movie and booking information is stored in Python dictionaries in memory. All booking records reset when the program exits.
