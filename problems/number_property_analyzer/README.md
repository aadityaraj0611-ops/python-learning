# Number Property Analyzer

A Python program that analyzes an integer and determines whether it is a **Prime Number**, **Perfect Number**, and **Armstrong Number**.

## Features

- **Prime Number Checker:** Checks whether a number has exactly two positive divisors.
- **Perfect Number Checker:** Checks whether the sum of a number's proper divisors equals the number itself.
- **Armstrong Number Checker:** Checks whether the sum of each digit raised to the power of the number of digits equals the original number.

## Example

**Input**
```text
153
```

**Output**
```text
Enter a positive integer: 153

--- Number Property Results ---
153 is not a Prime Number
153 is not a Perfect Number
153 is an Armstrong Number
```

## How to Run

Run the following command from the root of the repository:

```bash
python3 problems/number_property_analyzer/main.py
```

Enter an integer when prompted.
