# Fibonacci Sequence Generator

A simple Python program that generates the first `N` numbers of the Fibonacci sequence.

## Problem Statement

Given a positive integer `N`, print the first `N` numbers of the Fibonacci sequence.

In this sequence, each number after the first two is the sum of the previous two numbers.

The sequence starts with `0` and `1`.

## Example

**Input**
```text
8
```

**Output**
```text
0 1 1 2 3 5 8 13
```

## Features

- Generates the requested number of Fibonacci terms.
- Uses a loop to calculate the sequence.
- Handles non-positive input with an appropriate message.
- Uses a function to keep the code organized.

## How to Run

From the root of the repository, run:

```bash
python3 problems/fibonacci_sequence_generator/main.py
```

Enter the number of Fibonacci terms when prompted.
