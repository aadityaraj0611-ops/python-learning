# Fuel Cost and Mileage Calculator

A Python command-line application that calculates vehicle mileage, estimates fuel requirements for a journey, and calculates the expected fuel cost.

## Features

- Calculate vehicle mileage in kilometers per liter (km/L).
- Calculate the fuel required for a journey.
- Estimate the total fuel cost in Indian rupees.
- Validate non-positive input values.
- Interactive menu for performing multiple calculations.
- Exit the program whenever needed.

## How to Run

Make sure Python 3 is installed.

```bash
python3 problems/fuel_cost_mileage_calculator/main.py
```

## Example

For a journey of 300 km, a vehicle mileage of 15 km/L, and a fuel price of ₹100 per liter:

- Fuel required: 20 liters
- Estimated fuel cost: ₹2,000

## Concepts Used

- Variables and data types
- User input and output
- Functions and return values
- Conditional statements
- `while` loops
- Arithmetic operators
- Input validation
- `round()` and `strip()`

## Limitations

- The calculation assumes constant fuel efficiency.
- Actual fuel consumption and prices may vary.
- Non-numeric input is not handled yet.
