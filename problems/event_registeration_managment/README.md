# Event Registration Management System

A menu-driven Python application for managing participant registrations for college events.

## Features

- Register participants using unique roll numbers.
- Prevent duplicate registrations.
- Display all registered participants.
- Search for participants using roll numbers.
- Cancel participant registrations.
- Calculate the total number of registrations.
- Display registrations event-wise.
- Handle invalid menu inputs using exception handling.

## How to Run

1. Clone this repository.
2. Open the project directory in Terminal.
3. Run the following command:

```bash
python3 problems/event_registration_management/main.py
```

## Python Concepts Used

- Variables and data types
- Dictionaries and nested dictionaries
- Lists
- Functions
- While loops and for loops
- Conditional statements
- User input and type conversion
- Exception handling
- Dictionary methods

## Storage

Participant records are stored in a Python dictionary in memory. All registrations are reset when the program exits.
