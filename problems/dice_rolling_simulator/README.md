# Dice Rolling Simulator

A beginner-friendly Python project that simulates rolling one or two six-sided dice.

## Features

- Roll a single die.
- Roll two dice and calculate their total.
- Generate random results from 1 to 6.
- Repeat rolls without restarting the program.
- Handle invalid menu choices.
- Exit the program through the menu.

## Example

```text
===== Dice Rolling Simulator =====
1. Roll one die
2. Roll two dice
3. Exit

Enter your choice: 2
First die: 4
Second die: 6
Total: 10
```

*Note: Dice results are random, so your output will vary.*

## How to Run

From the root directory of the repository, run:

```bash
python3 problems/dice_rolling_simulator/main.py
```

## Concepts Practiced

- Importing Python modules
- Using `random.randint()`
- Variables and user input
- `while` loops
- `if`, `elif`, and `else`
- Arithmetic operations
- Basic input validation

## Learning Objective

This project demonstrates how Python's random number generation and conditional statements can be used to create a simple interactive game.
