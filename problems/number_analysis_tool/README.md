# Number Analysis Tool

A beginner-friendly Python program that analyzes a positive integer using loops and functions.

## Features

- Calculates the sum of digits
- Counts the number of digits
- Reverses the number using arithmetic operations
- Checks whether the number is a palindrome

## Example

Input:
5832

Output:
- Sum of digits: 18
- Number of digits: 4
- Reverse: 2385
- Palindrome: False

## How to Run

Run this command from the project directory:

python3 main.py

- Input and output
