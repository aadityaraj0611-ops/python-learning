# Number Guessing Game

A beginner-friendly Python game where the user tries to guess a secret number.

## Features

- Uses a secret number
- Tells the user whether their guess is too low or too high
- Repeats guesses until the correct number is entered
- Counts the total number of attempts
- Uses a function to check each guess

## Example

Input:
4
9
7

Output:
Too low
Too high
Correct!
You guessed the number in 3 attempts.

## How to Run

Run this command from the project directory:

python3 main.py
