# Roller Coaster Ride

A beginner-friendly Python program that checks roller coaster eligibility based on height and age.

## Rules

- Height below 120 cm: Not Allowed
- Age below 5 years: Not Allowed
- Height from 120 to 140 cm: Must ride with Adult
- Age from 5 to 12 years: Must ride with Adult
- Can ride alone only if height is above 140 cm and age is above 12 years.

The stricter restriction takes precedence.

## Ticket Prices

- Must ride with Adult: 200
- Can ride alone: 300
- Not Allowed: No ticket price is printed.

## How to Run

Run `python3 main.py` from this folder.

## Example

Input:
145
14

Output:
Can ride alone
300

## Concepts Practiced

- Input and output
- Integer conversion
- if/elif/else statements
- Logical operators
- Nested conditions
